## Batch runner and shared settings

`render_collection.py` discovers the current working inputs, checks that each has an explicit preset entry, loads the models once, and writes each image into its own subfolder in one new timestamped collection. It records source/input/model identifiers and checksums, per-image settings, success/failure summaries, final PNG checksums, a contact sheet and an original/result HTML gallery. A single failure is recorded and does not stop the remaining images. Nonzero exit status signals a failed image.

```bash
.venv/bin/python render_collection.py
# Optional repeat check:
.venv/bin/python render_collection.py --image mug3.jpg
```

The common finish uses float depth, 8-bit antialiasing, width scale 0.5, density 0.35, fine tapered fibres at 4x internal resolution, environment-tip blending 0.12, fur-coloured backing, radius-5 matte gap closing, backing fibres, opacity cap 1, depth ordering, strand contrast 0.12 and soft highlights 0.12. Guided cases retain rim strength 0.75 and rear-rim strength 0.85. Renderer/shading code was not changed for this batch.
