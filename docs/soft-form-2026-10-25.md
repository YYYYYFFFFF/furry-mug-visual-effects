# Mug3 soft-form trial

Date: 25 October 2026. Yifan clarified that the goal is to soften the cup's underlying shape: the previous render still reads as fur over a rigid ceramic object. Merely blending fibres across the rim does not address this. She authorized trying the proposed geometric deformation on one cup. Mug3 was selected; the ten-cup collection remains intact.

## Implementation

`soft_form.py` inserts a default-off stage after segmentation/matte repair and before normal estimation. It uses the explicit opening guide and object signed-distance field to create a variable outward displacement near the silhouette. Broad body weighting provides slight belly fullness; a smaller handle offset thickens its outline. Displacement is limited around enclosed holes and anchored at the foot. A small inward opening-boundary component adds room for a thicker lip. The field is spatially smoothed and inverted with damped iteration. Folded or poorly converged mappings are rejected.

The same inverse map transports foreground RGB, matte, relative depth and the opening guide. Mask-normalized sampling prevents new foreground pixels from inheriting background colours/depth. Background pixels outside the old/new object union remain byte-identical in the deformed source image. The code can inpaint previously occupied pixels exposed by contraction; this mug3 run exposes zero such pixels, so real-scene inpainting quality was not exercised here.

After transport, a foreground-normalized depth filter smooths the rim transition, while a rounded padding profile raises the front surface and lip in the renderer's relative-depth convention. The deep opening core is protected from body padding. Surface normals, mesh triangles, hair roots and strand paths are then regenerated. The previous hair width, density parameter, finish, tip tint, overlap order, rim finish and B lighting settings are retained.

This is a guided image-space/relative-depth approximation for an upright cup, not a 3D soft-body simulation or a full material/lighting reconstruction. The original photographed shadow is retained, with the base footprint anchored. The existing source depth and manual opening guide still limit the result.

## Full runs

- Baseline: `outputs/20261025-010814-all-mugs-fine-b/mug3`.
- Candidate: `outputs/20261025-125327-float-aa8-width0.5-underlayer-fur-fine4-env0.12-close5-fillgaps-cap1-orderdepth-rim0.75-rear0.85-contrast0.12-highlight0.12-soft8`.
- Disabled control: `outputs/20261025-125447-float-aa8-width0.5-underlayer-fur-fine4-env0.12-close5-fillgaps-cap1-orderdepth-rim0.75-rear0.85-contrast0.12-highlight0.12`.

```bash
.venv/bin/python fur_rendering_batch.py --image mug3.jpg --depth-source float --stroke-rasterizer aa8 --stroke-width-scale 0.5 --fur-finish fine --underlayer-mode fur --tip-environment-blend 0.12 --matte-close-radius 5 --fill-fur-gaps --fur-alpha-cap 1 --fur-order depth --rim-guide-mask data/region-masks/mug3-interior.png --rim-detail-strength 0.75 --rear-rim-strength 0.85 --strand-contrast 0.12 --strand-highlight 0.12 --soft-form 8
```

Remove `--soft-form 8` to reproduce the disabled control. The flag defaults to zero, accepts finite values in `[0, 12]`, and requires a single fine-fur image plus a rim guide. It cannot yet be combined with the old exclusion/inner-wall styling masks. The existing collection constructor retains default zero; its source-hash manifest now includes `soft_form.py`.

The amount scales with input dimensions. It is an overall displacement scale rather than a strict maximum: the combined outward and opening fields reach 8.38px in this run. Preview-only shape checks at 6 and 10 informed the modest choice of 8; only 8 received the full candidate render.

## Verification

- Disabled control final PNG is byte-identical to the accepted B result in the ten-cup collection.
- Object matte grows from 192,815 to 201,347 pixels, adding 8,532 real silhouette pixels. Zero original object pixels are vacated.
- The handle hole remains one enclosed opening: 13,665 to 11,842 pixels. The warped opening-guide area retains 98.59% of its original area.
- Inverse-map minimum determinant is 0.529, with maximum coordinate residual 0.0257px. No folded mapping was detected.
- Object mask and depth from row 553 downward are identical, fixing the geometric foot. This does not mean all regenerated hair-tip pixels near the base are identical.
- Deformed source RGB is unchanged outside the old/new object union. Final RGB more than 35px from that union is also unchanged; nearby exterior pixels can legitimately receive new fur.
- Twenty model-free tests pass, including five new checks for zero-strength identity, foreground-only sampling, background preservation, hole/foot constraints, valid mappings, determinism, immutable inputs and invalid input rejection. Six invalid CLI combinations are rejected; valid mug3 settings pass. Renderer CRLF line endings are preserved.

The primary strand count changes from 197,301 to 155,565. Although the density parameter remains 0.35, it is defined per estimated surface area. Depth rounding changes that area and geometry traversal, so this is not a pixel-matched comparison of identical hairs. Backing fibres are regenerated to cover sparse regions.

## Visual inspection and limits

Native-size and enlarged comparisons show a thicker, rounded front lip and slightly fuller body/handle. The front lip's transition is softer than the narrow hard-looking band in the accepted B baseline. The overall cylindrical mug structure remains recognizable; this is a restrained first trial and does not establish a completely soft stuffed-toy appearance. The user has not yet reviewed this candidate.

No other mug has been retuned or rerendered with soft form. The existing ten-cup gallery, inputs, preset and manual guides are retained. No release, tag or new local branch is created.
