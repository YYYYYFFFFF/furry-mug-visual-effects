# Rear cup rim: outward silhouette fibres

Date: 24 October 2026. Agent-assisted local refinement following Yifan's crop of the still-bald-looking top/back lip. The accepted rest of the cup is preserved. This is not a release approval.

## Diagnosis

The previous guided rim finish added short surface texture, but multiplied its support by existing fur coverage. It therefore could not generate a new fuzzy silhouette where old coverage was zero. Yifan's new crop points specifically to the upper rear contour: a relatively flat edge with only a few protruding strands. This requires actual outward fibres, not further colour variation within the existing surface.

The selected baseline is `outputs/20261024-210324-float-aa8-width0.5-underlayer-fur-fine4-env0.12-close5-fillgaps-cap1-orderdepth-rim0.75/`. The front surface finish is retained exactly.

## Local implementation

`apply_rear_rim_fringe` in `fur_rim.py` uses the same image-specific opening guide and the actual mug matte. Roots are restricted to the upper/rear arc and the first roughly 6 pixels inside the object silhouette. Their direction comes from a smoothed silhouette distance field with angular variation. About 70% of lengths are 4.5–8px and the remainder 8–12px on a 602px input, with curvature, width taper and fading tips.

The separate rear support fades from the object boundary into a small surrounding background region. It is not clipped against old fur alpha, so tips can create new coverage. It fades to zero at the opening guide's vertical midpoint and is restricted near the rear lip, preserving the front lip, body and deeper opening. This assumes an upright frontal mug view; it is not a general automatic rear-rim detector.

Root colours are sampled from the accepted rim appearance using foreground-weighted averaging. The existing fine-stroke rasterizer provides correct premultiplied alpha filtering and restrained background-colour tint at exterior tips. Tip tint samples the original photograph's background, not previously rendered fibres.

The optional flag is `--rear-rim-strength`, default `0`. A positive value requires `--rim-guide-mask`. The full candidate uses `0.85`, following previews at 0.75 and 1.0. Strength controls the added layer's opacity, not the number of fibres. The candidate adds 3,911 outward fibres with a separate fixed RNG; primary geometry and density remain unchanged.
