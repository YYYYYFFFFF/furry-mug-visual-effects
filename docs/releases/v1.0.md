# Furry Mug V1.0

Approved for publication by Yifan on 25 October 2026 after reviewing mug3 run `20261025-153141`. This is the first approved improved version after **Original program**. The reference result is the single mug3 image with rounded geometry, deeper short-pile interior and local lip lighting.

[GitHub Release](https://github.com/YYYYYFFFFF/furry-mug-visual-effects/releases/tag/v1.0) · [Saved result bundle](https://github.com/YYYYYFFFFF/furry-mug-visual-effects/releases/download/v1.0/furry-mug-v1.0-results.zip)

## Included work

- Float-precision depth, refined matte coverage, fine tapered fibres and soft environment-tinted tips.
- Depth-ordered overlap, fuller rim coverage, coherent strand contrast and highlights.
- Optional rounded soft-form geometry, recessed interior with 60% inner pile, and directional lip illumination plus soft inner contact shadow.
- Reproduction settings, inputs and source checksums, model cache identifiers/checksums, runtime inventory, diagnostic layers and comparisons packaged with the approved result.

The final geometry/lighting combination has been reviewed on **mug3 only**. The earlier ten-cup B collection used an earlier configuration; it is not presented as a ten-image validation of this release's final look. All features remain opt-in; use the command below for the approved appearance. `Final_Project.ipynb` remains the original course notebook.

## Reproduce the approved result

From the repository root, use the existing Python environment or install dependencies as described in the main README. Copy `data/input-images/mug3.jpg` into `image_folder/` if it is absent. The manual opening guide is tracked at `data/region-masks/mug3-interior.png`.

```bash
.venv/bin/python fur_rendering_batch.py \
  --image mug3.jpg --depth-source float \
  --stroke-rasterizer aa8 --stroke-width-scale 0.5 \
  --fur-finish fine --underlayer-mode fur --tip-environment-blend 0.12 \
  --matte-close-radius 5 --fill-fur-gaps --fur-alpha-cap 1 --fur-order depth \
  --rim-guide-mask data/region-masks/mug3-interior.png \
  --rim-detail-strength 0.75 --rear-rim-strength 0.85 \
  --strand-contrast 0.12 --strand-highlight 0.12 \
  --soft-form 8 --cavity-depth 0.055 --cavity-length-scale 0.6 \
  --rim-light 0.25 --rim-shadow 0.28
```

The saved run used cached models with `HF_HUB_OFFLINE=1`; a first run requires model downloads. Exact observed package/model details are in the asset manifest. The existing environment used Python 3.9.6 and shared installed packages; a clean cross-platform installation and cross-hardware bitwise reproduction have not been validated.
