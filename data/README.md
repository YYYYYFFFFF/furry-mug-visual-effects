# Input image data

This folder keeps the ten original mug test images apart from the program files. `manifest.json` records each file's SHA-256 checksum and byte size. The photos were copied from the COMP5405 course project's `image_folder/`; their original sources and public reuse permissions are not yet verified, so keep the GitHub repository private until those rights have been checked.

The batch script reads from `image_folder/`. After cloning, copy the desired test images from `data/input-images/` into `image_folder/` before running it. The reference paper, model weights, and generated outputs are not stored here. Approved output bundles belong to their matching GitHub Releases.
